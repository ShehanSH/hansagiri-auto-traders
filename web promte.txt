27. FIRESTORE SECURITY
==================================================

Security is extremely important.

Implement strict Firestore Security Rules.

Public users:

Can READ only published/available vehicle information.

Public users:

Can CREATE:

- inquiries
- test drive requests
- trade-in requests
- contact messages

Public users must NOT:

- Read customer records
- Read inquiries
- Read trade-ins
- Read contact messages
- Read admin records
- Modify vehicles
- Delete vehicles
- Modify settings
- Modify other customers' data

Admin users:

Can access protected collections according to role.

Do not use:

allow read, write: if true;

Do not use insecure development rules in production.
